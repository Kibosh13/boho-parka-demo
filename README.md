# Лендинг «Перекрой шубы — БОХО ПАРКА»

Готовый адаптивный сайт-визитка без фреймворков и сторонних библиотек.

## Состав

- `index.php` — основная PHP/HTML-страница;
- `assets/css/style.css` — все стили и адаптивные состояния;
- `assets/js/main.js` — мобильное меню, плавные переходы без хэшей в URL и просмотр фотографий;
- `assets/images/` — оптимизированные фотографии и логотип.

## Установка

Загрузите содержимое папки в корневой каталог сайта на хостинге с PHP. Главная страница откроется через `index.php`.

## Реализовано

- строгая последовательность блоков исходной структуры;
- бесконечная автоматическая прокрутка клиентской галереи;
- остановка галереи при наведении курсора или фокусе с клавиатуры;
- увеличение всех фотографий с листанием и клавишами-стрелками;
- адаптация под компьютер, планшет и телефон;
- навигация по разделам без `#about`, `#works` и других хэшей в адресной строке;
- уменьшение движения для пользователей с включённой системной настройкой `prefers-reduced-motion`;
- фирменная палитра и корректное использование логотипа;
- прямые ссылки на телефон, электронную почту, MAX, Telegram, WhatsApp, ВКонтакте и YouTube.
