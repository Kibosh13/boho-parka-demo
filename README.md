# BOHO! PARKA — перекрой шубы

Статический лендинг мастерской Натальи Неклюдовой. Для публикации на GitHub Pages используется `index.html`; исходный файл `index.php` не содержит серверного PHP-кода и сохранён как часть переданного проекта.

Демонстрация закрыта от поисковой индексации через meta robots и `robots.txt`.
